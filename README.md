# Учебная практика УП 01.02 — Лабораторная работа №1

**Тема:** мини-приложение «Карточка товара со счётчиком» на React.

**ПМ.01** «Разработка модулей программного обеспечения для компьютерных систем»,
специальность 09.02.07 «Информационные системы и программирование».

## Задание

1. Создать React-проект (Vite) и компонент `ProductCard`, получающий через props
   название товара, цену и изображение.
2. Добавить кнопку «Добавить в корзину» со счётчиком: при каждом нажатии
   количество увеличивается на 1 и отображается на карточке.
3. Для хранения количества использовать хук `useState` внутри `ProductCard`.
4. В компоненте `App` отобразить несколько карточек товара с разными данными,
   передавая их через props. Счётчик каждой карточки независим от других.

## Структура репозитория

- `Desktop/УП/pr1` — приложение (Vite + React);
- `Desktop/УП/лекции` — лекционные материалы;
- `Desktop/УП/шаблон` — шаблон отчёта;
- `Desktop/УП/отчёт` — готовый отчёт по лабораторной работе.

## Запуск приложения

```bash
cd Desktop/УП/pr1
npm install
npm run dev
```

После запуска открыть в браузере адрес, который выведет Vite
(по умолчанию http://localhost:5173).

Другие команды:

- `npm run build` — production-сборка;
- `npm run preview` — локальный просмотр production-сборки;
- `npm run lint` — проверка кода ESLint.
